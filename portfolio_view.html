🚀 PromptStudio AI — Full-Stack AI Prompt Engineering Platform

PromptStudio AI adalah platform cerdas cross-platform yang dirancang untuk mempermudah generasi prompa (prompt) AI terstruktur secara otomatis bagi kreator konten, marketer, dan pengembang. Terintegrasi langsung dengan model LLM canggih Groq Cloud (Llama 3.3 70B & Llama 3.2 11B Vision) serta dilengkapi sistem rotasi API Key otomatis, platform ini menghadirkan pengalaman pembuatan konten iklan viral, carousel edukasi, deskripsi produk digital, hingga pembuatan prompt logo secara efisien dan andal.

📌 Tanggung Jawab & Fitur Utama Project:

  • Arsitektur Client-Server & Offline Cache: Membangun aplikasi mobile Flutter dengan state management Provider serta lokal database cache (SQLite/Sqflite) untuk performa responsif dan dukungan offline.
  • API Gateway & Key Rotation System: Mengembangkan backend gateway berbasis Node.js, Express, dan TypeScript yang menyajikan sistem rotasi otomatis Groq API Key guna menjamin keandalan sistem tanpa downtime.
  • Web Admin Panel Dashboard: Merancang antarmuka Web Admin intuitif untuk pengelolaan CRUD gaya desain visual, kategori audiens target, katalog template, dan konfigurasi profil AI.
  • Integrasi Multi-Cloud Services: Menghubungkan basis data transaksional MySQL, cloud storage ImageKit untuk manajemen aset gambar, dan RESTful API Groq AI Cloud.

🛠️ Teknologi & Stack Digunakan:

Flutter Dart Node.js Express.js TypeScript Groq Cloud LLM Llama 3.3 70B MySQL SQLite / Sqflite ImageKit Cloud RESTful API
💡 Highlight Kompetensi & Nilai Tambah: Demonstrasi keahlian merancang arsitektur aplikasi end-to-end (Mobile Client & Backend Gateway), integrasi AI LLM tingkat lanjut dengan ketahanan sistem tinggi (Automatic API Key Failover), serta penerapan caching hybrid offline-first untuk UX yang optimal.
